수학 문항 숫자 평가 프로그램

본인이 수학 문항 제작할 때 문제의 질은 문제의 풀이에 필요한 사고 과정 뿐 아니라 계산의 복잡량에 의해서도 영향을 받는다.
따라서 정답, 발문, 풀이과정의 숫자들이 자연수, 정수, 익숙한 숫자인 것이 중요하다.
이 프로그램은 수학 문제를 제작할 때 사용하는 숫자가 적절한지 평가하는 간단한 파이썬 프로그램이다.
정답, 발문, 풀이과정 등 숫자의 용도에 따라 적절한 숫자인지 판단하는 구조이다.

<구성>

1) 정답
자연수를 가장 적절한 정답으로 판단한다.
0, 음수, 정수가 아닌 수는 추천하지 않는다.

2) 발문에 등장하는 숫자
정수를 우선적으로 추천한다.
정수가 아닌 경우 유리수의 크기와 분모를 고려한다.(recommended와 acceptable로 층위를 나누었다.)

3) 계산 과정에 등장하는 숫자
정수를 우선적으로 추천한다.
정수가 아닌 경우 유리수의 크기와 분모를 고려한다.(recommended와 acceptable로 층위를 나누었다.)

4) 지수함수와 로그함수의 밑
2, 3, 4를 추천한다.
밑은 양수여야 하며 1은 사용할 수 없다.

5) 다항함수의 최고차항 계수
최고차항 계수가 1인 경우를 추천한다.
최고차항 계수는 0이 될 수 없다.

6) 유리수 평가 기준
발문이나 계산 과정에 정수가 아닌 유리수가 등장하는 경우 다음 두 조건을 확인한다.
1. 유리수의 절댓값이 5 이하인가?
2. 기약분수로 나타냈을 때 분모가 2, 3, 4 중 하나인가?

두 조건을 모두 만족하면 추천하고, 하나만 만족하면 사용 가능한 숫자로 판단한다. 두 조건을 모두 만족하지 못하면 추천하지 않는다.
정수인 경우에는 위 조건과 관계없이 우선적으로 추천한다.

<사용방법>
1. 숫자의 용도를 1~5 중에서 선택한 후 평가할 숫자를 입력한다.
2. 정수, 소수, 분수 형태로 입력할 수 있다.
3. 예를 들어 발문에 등장하는 숫자로 3/2를 입력하면 절댓값과 분모 조건을 모두 만족하므로 추천한다.
